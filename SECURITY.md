# Güvenlik Politikası (Security Policy)

Bu proje, açık veri entegrasyonlarının güvenliğini ve veri bütünlüğünü ciddiye alır.

## Desteklenen Sürümler

Aşağıdaki tabloda güvenlik güncellemelerini aktif olarak alan sürümler belirtilmiştir:

| Sürüm | Destek Durumu |
| --- | --- |
| `0.2.x` | Destekleniyor |
| `< 0.2.0` | Desteklenmiyor |

## Güvenlik Açığı Bildirimi

Bir güvenlik açığı tespit ettiyseniz lütfen bunu herkese açık GitHub Issue olarak bildirmeyin.

1. **İletişim Kanalı:** Bildiriminizi doğrudan `atacanymc@gmail.com` adresine e-posta ile gönderin.
2. **Bildirim Detayları:**
   - Açığın türü ve etkisi (SSRF, Path Traversal, DoS vb.)
   - Yeniden üretim adımları veya kavram kanıtlama (PoC) kodu
   - Etkilenen kütüphane bileşenleri veya fonksiyonlar
3. **Yanıt Süresi:** Bildirimlere en geç 48 saat içinde ilk yanıt verilir.
4. **Düzeltme ve Yayınlama:** Güvenlik açığı doğrulandıktan sonra bir yama hazırlanır, sürüm yayınlanır ve katkı veren araştırmacıya teşekkür edilir.
